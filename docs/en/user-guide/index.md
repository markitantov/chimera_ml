# User guide

Use this section when you have a task package and need to perform a specific
operation.

- [Configuration reference](configuration.md) — fields, defaults, and the
  name/params contract.
- [Data](data.md) — datamodules, collates, masks, and multiple loaders.
- [Models](models.md) — Batch/ModelOutput and built-in fusion models.
- [Training](training.md) — Trainer.fit, mixed precision, scheduling, and
  checkpoints.
- [Evaluation](evaluation.md) — checkpoint loading and split metrics.
- [Losses](losses.md), [Metrics](metrics.md) — built-in primitives and plugin
  interfaces.
- [Optimizers and schedulers](optimizers-schedulers.md) — built-ins and config.
- [Callbacks](callbacks.md) — lifecycle hooks and artifacts.
- [Logging](logging.md) and [MLflow](mlflow.md) — local and experiment tracking.
- [Inference](inference.md) — sequential and DAG pipelines.
- [Sweeps](sweeps.md) — grid and Optuna trials.
- [Plugins](plugins.md) — add task components.
- [CLI workflows](cli.md) and [Troubleshooting](troubleshooting.md).
