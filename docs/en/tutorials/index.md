# Tutorials

These tutorials are adapted from the real example packages in this repository.
They are not synthetic minimal projects: each example requires the data,
features, checkpoints, and external dependencies listed on its own page.

- [VA estimation](va-estimation.md): audio and multimodal valence/arousal
  training and evaluation.
- [ORAGEN](oragen.md): audio-visual age/gender/mask pipelines and video
  inference.
- [Affective states recognition](affective-states-recognition.md): multimodal
  emotion and sentiment training/inference.

For the framework-level first path, start with [First experiment](../getting-started/first-experiment.md).
