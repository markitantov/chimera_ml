# Changelog

The canonical release history is [CHANGELOG.md](https://github.com/markitantov/chimera_ml/blob/main/CHANGELOG.md)
in the repository. It follows Keep a Changelog and Semantic Versioning.

states example and inference artifact merging), 0.2.3 (inference pipeline,

0.2.0 (sweep), and 0.1.0 (initial public package).

Read the linked file for the exact historical facts and dates.
