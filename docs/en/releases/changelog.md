# Changelog

The canonical release history is [CHANGELOG.md](https://github.com/markitantov/chimera_ml/blob/main/CHANGELOG.md)
in the repository. It follows Keep a Changelog and Semantic Versioning.

The `0.3.1` release includes the built-in feature-only fusion models,
`MultimodalSequenceCollate`, mask-safe attention behavior, and the migration
away from external fusion encoders and heads. The current `Unreleased` section
covers XAI and documentation improvements. This page is an index, not a
competing release history.

Current documented releases include 0.3.1 (feature-only fusion architectures and independent sequence collate), 0.3.0 (Optuna sweeps), 0.2.5.post1 and
0.2.5 (sweep metadata/naming and PDF confusion matrices), 0.2.4 (affective
states example and inference artifact merging), 0.2.3 (inference pipeline,
checkpoint resolution, and ORAGEN), 0.2.2 (trainer fixes), 0.2.1 (BuildContext),
0.2.0 (sweep), and 0.1.0 (initial public package).
