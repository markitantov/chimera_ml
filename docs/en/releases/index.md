# Releases

- [Changelog](changelog.md) presents the canonical Keep a Changelog history.
- [Migration guide](migration.md) translates confirmed behavior changes into
  actions for users.

The package follows Semantic Versioning. Version `0.3.1` is the current
released version documented by the canonical changelog; XAI and documentation
updates remain in `Unreleased`. The changelog remains the source of truth for
release facts; this site does not maintain a second release history.
