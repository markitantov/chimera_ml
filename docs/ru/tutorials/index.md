# Практические примеры

Эти tutorials основаны на реальных example packages репозитория. Для каждого
могут потребоваться data, features, checkpoints и external dependencies.

- [VA estimation](va-estimation.md) — audio и multimodal valence/arousal.
- [ORAGEN](oragen.md) — audio-visual age/gender/mask и video inference.
- [Affective states recognition](affective-states-recognition.md) — emotion
  и sentiment на audio, video и text.

Сначала можно пройти [Первый эксперимент](../getting-started/first-experiment.md).
