# Расширение CHIMERA-ML

Автор расширения реализует компонент, специфичный для задачи, по публичному контракту и регистрирует функцию построения под стабильным ключом. Набор данных, модель, функцию потерь и колбэки следует размещать в Python-пакете или плагине, а не изменять исходный код ядра.

- [Реестры](registries.md) — поиск компонентов, функции построения и повторяющиеся ключи.
- [BuildContext](build-context.md) — метаданные построения, а не артефакты инференса.
- [Плагины](plugins.md) — полноценный устанавливаемый плагин.
- [Пользовательские данные](data.md), [модели](models.md), [компоненты обучения](training.md) и [колбэки](callbacks.md).
- Для инференса используйте полное руководство по [пользовательским шагам](../inference/custom-steps.md) и инструкции по упаковке из раздела [Плагины](plugins.md).

Основные контракты компактны: элемент набора данных — отображение, модель — `Batch → ModelOutput`, функция потерь — вызываемый объект для результата и батча, метрика — `reset/update/compute`, колбэк — набор хуков жизненного цикла.
