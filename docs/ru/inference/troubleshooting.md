# Устранение проблем

- **Шаг не найден.** Установите плагин в то же окружение и выполните `chimera-ml registry list --type inference_steps`. В YAML нужен ключ реестра, а не имя класса Python.
- **Неверная команда валидации.** `chimera-ml validate-config` проверяет `ExperimentConfig` обучения и оценки, а не YAML инференса. Для инференса сверяйте поля со [схемой конвейера](pipeline.md) и registry.
- **Нет `predictions`.** Шаг предсказания должен вызвать `ctx.set_artifact("predictions", value)` до шага печати или записи.
- **Не найден вход.** CLI проверяет существование `--input`; подготовьте файл заранее.
- **CUDA недоступна.** Используйте `--device cpu` или `runtime.device: cpu`; `auto` выберет CPU, если CUDA недоступна.
- **Конфликт артефактов.** В параллельном DAG свяжите перезаписывающий узел через `after` с владельцем артефакта либо используйте разные имена.
- **Цикл или неизвестная зависимость `after`.** Проверьте уникальность `id` и направление зависимостей.
- **Не скачивается контрольная точка.** Разрешены только HTTP(S); проверьте сеть, права `work-dir` и место для `.part`.
- **XAI не запускается.** Модель и вложенные модули должны быть в `eval()`, а шаг предсказания должен иметь атрибут `on_prediction` (он может быть `None` до wrapping).
- **В JSON нет XAI.** `write_json_predictions_step` экспортирует только `input` и `predictions`; получите `result.get_artifact("xai")` и сохраните результат отдельным средством записи.
- **JSON не сериализуется.** Преобразуйте tensors и другие значения в форму, совместимую с JSON в прикладном шаге.
