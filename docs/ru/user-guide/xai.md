# Шаг объяснимости модели

Шаг XAI измеряет локальную чувствительность предсказания к исключению одной
модальности. Для выбранной оценки h вычисляется

    delta_m = h(f(x_S)) - h(f(x_(S без m))).

Изменение имеет знак: он показывает направление изменения оценки после
исключения модальности. Артефакт сохраняет отдельные изменения, покадровые
результаты, маски выходов и диагностику модели. Он не строит ранжирование,
сводные показатели и метрики качества выборки.

## Контракт обратного вызова

xai_step оборачивает шаг предсказания. Обёрнутый шаг должен иметь атрибут
on_prediction и вызывать его сразу после каждого прямого прохода модели.
Обратный вызов получает ту же модель, пакет Batch и результат ModelOutput,
которые использовались для обычного предсказания. xai_step временно
устанавливает собственный сборщик, вызывает прежний обратный вызов, если он
был, и восстанавливает его даже при ошибке вложенного шага.

Модель и все её вложенные модули должны находиться в режиме оценки.
explain_batch выполняется в режиме inference_mode. Модель может дополнительно
реализовать validate_intervention(original, intervened, modality, policy) ->
str | None. Возвращённая причина помечает сравнение как неподдерживаемое, и
изменённый проход модели не выполняется. Неожиданные ошибки проверки и модели
передаются вызывающему коду.

## Настройка

~~~yaml
- name: xai_step
  params:
    step:
      name: fusion_step
      params: {}
    modalities: [audio, video]
    ablation_policy: remove
~~~

Вложенный шаг можно передать уже созданным объектом. Функции score_fn и
output_mask передаются из кода Python и не записываются в YAML.

## Параметры

- step — шаг предсказания с обратным вызовом.
- modalities — выбранные имена входов; если параметр не задан, используются все
  имена, полученные при обработке пакетов.
- score_fn — необязательная функция ModelOutput -> tensor. Без неё сравнивается
  output.preds.
- output_mask — имя маски или функция, возвращающая тензор формы оценки либо
  формы оценки без последней компоненты.
- ablation_policy — remove или mask.

remove удаляет выбранный вход и связанные с ним маски. mask сохраняет вход и
сбрасывает существующие связанные маски; если их нет, создаётся основная маска
модальности, полностью запрещающая её использование. Обе политики действительно
исключают модальность. Варианта с заменой значений на нули нет.

## Артефакт

В контекст записывается artifacts["xai"]:

~~~python
{
    "ablation_policy": "remove",
    "modalities": ["audio", "video"],
    "samples": [
        {
            "sample_id": "sample-0",
            "baseline": 0.42,
            "modalities": {
                "audio": {
                    "status": "evaluated",
                    "reason": None,
                    "delta": 0.08,
                    "prediction": 0.34,
                }
            },
            "aux": {"frame_weights": [[0.6, 0.4]]},
        }
    ],
}
~~~

Статусы: evaluated, already_missing и unsupported. Недопустимые позиции
записываются как null. При обработке нескольких пакетов список модальностей
является детерминированным объединением настроенных имён и имён, полученных из
результатов обратного вызова.

## Диагностика моделей

TFS сохраняет внимание и веса направленных пар и групп. RAAV сохраняет
кадровые веса, маски кадров, контекстное внимание, внимание сжатия и контекстные
поправки. TOMAR сохраняет веса и поправки. Эти значения описывают внутреннее
слияние и не объявляются причинной важностью.
