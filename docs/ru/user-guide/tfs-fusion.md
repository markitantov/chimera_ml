# Слияние TFS

TFSFusionModel выполняет иерархическое двунаправленное слияние. Признаки
каждой настроенной модальности переводятся в общую размерность. Для каждой
направленной пары выполняется межмодальное внимание. В паре `A->B` запросы
формируются из A, а ключи и значения — из B. Результаты пар объединяются по
оси последовательности (`dim=1`) внутри каждой группы, поэтому длины
последовательностей модальностей могут различаться. Для каждой уточнённой
группы применяется StatPool с учётом маски; он возвращает популяционные
среднее и стандартное отклонение. Представления доступных групп затем
усредняются арифметически и проходят через Linear, BatchNorm и Tanh перед
предсказанием.

## Конструктор

~~~python
TFSFusionModel(
    input_dims: dict[str, int],
    shared_dim: int,
    output_dim: int,
    groups: Sequence[Sequence[Sequence[str]]] | None = None,
    dropout: float = 0.1,
    max_position_length: int = 5000,
)
~~~

Если groups не задан, создаются две группы: прямые и обратные направления
каждой неупорядоченной пары. Каждая направленная пара должна встречаться один
раз. Пустые группы, неизвестные модальности, пары модальности с самой собой и
повторные пары приводят к ValueError.

Пользовательские группы могут содержать любое непустое подмножество направленных
взаимодействий; пропущенные пары не вычисляются. Если groups не задан, модель
создаёт полную прямую и полную обратную группу для каждой неупорядоченной пары
модальностей.

Сначала для каждой уточнённой группы применяется StatPool с учётом маски. Затем
доступные векторы групп усредняются арифметически, без второго статистического
свёртывания. Контрольные точки предыдущей реализации с двойным свёртыванием
несовместимы с текущей структурой параметров; автоматического преобразования нет.

## Входы и выходы

Входные признаки имеют форму [B, D] или [B, T, D]. Результат имеет форму
[B, output_dim]. Маски времени и наличия читаются из Batch; маска времени
имеет приоритет. sequence_mask объединяется с маской модальности, если формы
совпадают.

В aux возвращаются представления пар, маски их допустимости, коэффициенты
внимания пар и групп, group_weights и fused. Эти значения являются
диагностикой модели и доступны шагу XAI.

В пакете должны присутствовать признаки как минимум двух настроенных
модальностей. Полностью замаскированная пара сохраняется как недопустимый
нулевой вклад.

## Пример

~~~python
import torch
from chimera_ml.core import Batch
from chimera_ml.models import TFSFusionModel

model = TFSFusionModel(
    {"text": 4, "audio": 5, "video": 6},
    shared_dim=8,
    output_dim=2,
).eval()

batch = Batch(
    inputs={
        "text": torch.randn(2, 3, 4),
        "audio": torch.randn(2, 3, 5),
        "video": torch.randn(2, 3, 6),
    },
    targets=None,
)
output = model(batch)
assert output.preds.shape == (2, 2)
~~~

Ключ в реестре: tfs_fusion_model.
