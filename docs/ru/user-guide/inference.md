# Обзор инференса

Инференс — независимый механизм выполнения, управляемый конфигурацией. `InferencePipeline` выполняет шаги над одним входным путём и общим `InferenceContext`; это не сокращённый вариант обучения или оценки.

```text
Входной путь -> InferenceContext -> подготовка -> чекпоинты -> предсказание
           -> XAI (необязательно) -> постобработка -> артефакты
```

Обучение (`Trainer.fit`) обновляет параметры по DataLoader и сохраняет чекпоинты. Оценка (`chimera-ml eval`) запускает модель на настроенных размеченных split-ах и считает метрики. Инференс (`chimera-ml inference`) запускает прикладной pipeline для входного файла и обычно экспортирует предсказания; параметры модели не обновляются.

Ядро предоставляет `InferenceConfig`, `InferenceContext`, планировщик pipeline, реестр `INFERENCE_STEPS`, разрешение чекпоинтов, JSON-вывод и универсальную XAI-обёртку. Прикладной пакет или плагин предоставляет подготовку входа, построение модели, загрузку весов и шаг предсказания: универсального core-шага для любой задачи нет.

Шаги обмениваются данными через контекст: `input_path`, `work_dir`, разрешённое устройство `cpu`/`cuda` и именованные артефакты. Соглашение для результата — артефакт `predictions`; шаг записи превращает его в JSON.
