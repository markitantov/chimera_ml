# Журнал изменений

Каноническая история находится в [CHANGELOG.md](https://github.com/markitantov/chimera_ml/blob/main/CHANGELOG.md)
репозитория. Она использует форматы Keep a Changelog и Semantic Versioning.

Релиз `0.3.1` включает встроенные модели слияния только по признакам,
`MultimodalSequenceCollate`, безопасное для масок внимание и переход от внешних
энкодеров и голов слияния. Текущая секция `Unreleased` посвящена XAI и улучшениям
документации. Эта страница является индексом, а не отдельной историей релизов.

Последние записи охватывают 0.3.1 (модели слияния только по признакам и collate для независимых последовательностей), 0.3.0 (переборы Optuna), 0.2.5.post1/0.2.5
(метаданные и именование переборов, PDF-матрицы ошибок), 0.2.4 (аффективные
состояния и объединение артефактов инференса), 0.2.3 (конвейер инференса, разрешение
контрольных точек, ORAGEN), 0.2.2, 0.2.1 (BuildContext), 0.2.0 (перебор) и 0.1.0.
Точные факты и даты находятся в связанном файле.
