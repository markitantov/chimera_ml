# Обзор обучения

Обучение CHIMERA-ML — конфигурационный сценарий `Trainer.fit`, который связывает данные, модель, функцию потерь, метрики и компоненты управления запуском:

```text
Dataset -> DataModule -> DataLoader -> Collate -> Batch -> Model
        -> ModelOutput -> Loss/Metrics -> Optimizer -> Trainer
        -> Callbacks/Loggers -> Checkpoints
                           \-> Scheduler
```

## Порядок работы

1. Датасет плагина читает образцы с входами модальностей, целевыми значениями и метаданными.
2. DataModule строит загрузчики для обучающей, валидационной и тестовой выборок и может вернуть именованные загрузчики.
3. Collate-функция превращает образцы в `Batch`, дополняет последовательности и создаёт маски.
4. Trainer переносит батч на устройство и вызывает `model(batch)`.
5. Функция потерь получает `ModelOutput` и `Batch`, а метрика качества обновляет своё состояние по размеченному батчу.
6. Обучение выполняет обратное распространение, при необходимости ограничивает градиенты, а затем делает шаг оптимизатора и планировщика.
7. После эпохи обучения запускается проверка; колбэки получают плоские журналы вроде `train/loss`, `val/loss` и ключи метрик.
8. Журналировщики сохраняют журналы, метрики и артефакты, а колбэк контрольных точек записывает состояние модели.

Ядро предоставляет `Batch`, `ModelOutput`, `DataModule`, collate-функции, Trainer, строители, встроенные компоненты и CLI. Проект предоставляет данные задачи и обычно регистрирует DataModule, модель, функцию потерь и метрики. Сигнатуры фабрик плагина определяют параметры, специфичные для плагина.

## Команды

```bash
chimera-ml validate-config --config-path config.yaml
chimera-ml train --config-path config.yaml
chimera-ml eval --config-path config.yaml --checkpoint-path logs/.../checkpoints/last.pt
```

Обучение обновляет параметры; оценка не выполняет шагов оптимизатора. Инференс для развёртывания — отдельный конвейер в разделе «Инференс».
